## how it works

01

Compose visually

Click cards to add segments; drag to reorder; add ⏎ line breaks for multi-row bars. A live ticker fakes a real session so you see thresholds flip green → yellow → red.

02

Copy for Claude

copy for Claude produces a precise build spec — rows, sources, glyphs, exact truecolor hexes, caching rules. 📸 screenshot captures the target rendering as a PNG.

03

Paste & verify

Paste both into Claude Code. Claude writes ~/.claude/statusline.sh, wires up settings.json, and compares its output against your screenshot until it matches.

## what's inside

65

Data points, categorized

Native stdin JSON, git, GitHub CLI, dev environment, system — plus derived ideas like burn rate, compact ETA, and a next-meeting countdown.

▓▓░

Honest simulation

Threshold colors, conditional segments that hide when inactive, multi-row layouts, truncation warnings past 80 chars — the bar behaves like the real one.

#hex

Truecolor fidelity

The spec pins every segment to a 24-bit ANSI color, so what you designed is what your terminal renders — no theme drift.
